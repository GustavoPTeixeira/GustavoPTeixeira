I started my tech journey as a full-stack developer, then realized what I enjoyed most was hunting edge cases, mapping risk, and building the test architecture that keeps bugs out of production. Today I bring a software engineering mindset to Quality Assurance, working across the UI, the APIs, and the data layers underneath.
 
My focus is **shift-left testing**: getting automation into CI/CD early, validating business logic where it actually lives (databases and message queues, not just the screen), and using AI tools to shorten the path from *"a test failed"* to *"here's why."*
 
### 📈 Impact Highlights
- 🎭 **Led a Cypress → Playwright migration** and set up Jenkins CI/CD pipelines, raising automation coverage from **35% to 85%**.
- 🤖 **Brought Claude AI into the daily QA workflow**, speeding up automation script delivery and root-cause analysis by **60%**.
- 🗄️ **Validated data end to end** across PostgreSQL, Oracle, MongoDB, Kafka, and RabbitMQ to keep reporting dashboards and message queues consistent.
- 🧑‍🏫 **Mentored junior QA engineers** in automation best practices, test design, and effective bug reporting.
### 💡 What I Do
- **End-to-End Automation:** Scalable, maintainable UI suites with **Playwright** and **Cypress**.
- **API & Backend Validation:** Testing REST APIs and checking business logic directly in **SQL**, **MongoDB**, **Kafka**, and **RabbitMQ**.
- **AI-Assisted Engineering:** Using **Claude** and **Claude Code** to generate test scripts, refactor code, and run fast root-cause analysis.
- **Performance & Accessibility:** Load testing with **JMeter** and **NeoLoad**, and WCAG accessibility audits with **NVDA**.

- **Tooling & DX (Developer Experience):** Building internal tools and CLIs that make QA engineers' lives easier.

### 🚀 Featured Projects
 
#### 📊 [QA-Metrics-Dashboard](https://github.com/GustavoPTeixeira/QA-Metrics-Dashboard)
An open-source quality governance platform that combines defect data from **Jira**, **GitHub Issues**, and **Azure DevOps** with CI/CD test results (JUnit, Allure, Playwright, Pytest). It gives engineering leaders clear answers on bug MTTR, regression risk, flaky tests, and production escapes.
- **Features:** Executive KPI row with SLA checks, a severity × module risk heatmap, a flaky-test quarantine table, tracker webhooks and sync, and Slack alerts for P1 defects and SLA breaches.
- **Stack:** **Python / FastAPI**, SQLAlchemy, PostgreSQL / DuckDB, **Next.js / React / TypeScript**, Tailwind CSS, and Docker Compose. Tested with Pytest against a reproducible synthetic dataset.
#### 🧰 [automation-project-simplifier](https://github.com/GustavoPTeixeira/automation-project-simplifier)
An open-source **Node.js** CLI that scaffolds and standardizes new test automation projects. Instead of spending hours on boilerplate and folder structures, QA teams are ready to write tests in minutes.
 
#### 📚 [DELTA](https://github.com/GustavoPTeixeira/Delta)
A cross-platform educational app built with **Flutter/Dart** and **Firebase** that encourages reading habits and an interest in science among 9th-grade students, using popular-science texts and gamification.
- **Features:** User registration and profiles, a subject-based menu, a reading mode with curated scientific texts, and quizzes that measure reading comprehension.
- **Background:** Started as my undergraduate thesis (TCC) on the impact of technology in childhood education, originally built with Java, Android Studio, Spring Boot, and MySQL, and since rebuilt in Flutter.
