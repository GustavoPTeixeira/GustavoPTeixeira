An open-source CLI tool built in **Node.js** designed to streamline, standardize, and accelerate the initialization of new test automation projects. Instead of spending hours setting up boilerplates and folder structures, this tool gets QA teams ready to write tests in minutes.

**[DELTA](https://github.com/GustavoPTeixeira/Delta)**
An educational mobile application aimed at fostering reading habits and sparking an interest in science among 9th-grade students. The platform features scientific popularization texts and incorporates gamification elements to engage users in a dynamic learning environment.
* **Key Features:** Includes user registration and profile management, a categorized menu of school subjects, a reading mode with tailored scientific texts, and an interactive questionnaire system to evaluate reading comprehension.
* **Project Background:** Originally designed as my final paper (TCC) to evaluate the impact of technology on childhood education, initially utilizing a tech stack of Java, Android Studio, MySQL, and Spring Boot. The active development in this repository has been modernized using **Flutter/Dart** and **Firebase**.
